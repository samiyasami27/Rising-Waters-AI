# 🌊 Rising Waters – AI Flood Prediction System

## 📌 Overview

Rising Waters is an AI-powered Flood Prediction System developed using Machine Learning. The application predicts flood probability based on environmental and geographical parameters.

## 🚀 Features

- Flood Probability Prediction
- XGBoost Machine Learning Model
- Flask Web Application
- User-friendly Interface
- AI Safety Recommendations
- Risk Level Classification

## 🛠 Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Joblib
- HTML
- CSS

## 🤖 Machine Learning Models

- Decision Tree
- Random Forest
- KNN
- XGBoost ✅ (Best Model)

## 📊 Model Performance

| Model | R² Score |
|--------|-----------|
| Decision Tree | ~0.11 |
| Random Forest | ~0.73 |
| KNN | ~0.77 |
| XGBoost | ~0.90 |
